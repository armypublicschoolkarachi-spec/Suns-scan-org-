# Sun Scan website starter

Responsive multi-page static site with original Sun Scan branding and a dark/crimson scanlation-inspired design.

## Pages
index, browse, series, reader, bookmarks, login, blog, recruitment, donate, contact, about, privacy, dmca, admin.

## Run
Unzip and open `index.html` in a browser, or serve the folder with any static web server.

## Prototype limitations
Bookmarks, catalogue edits and chapter additions use localStorage in this browser only. Forms are demo-only. Reader pages use stylized placeholder panels, not actual comic pages. A production site needs a backend/database, secure admin authentication, real image storage/uploads, email handling, backups and a deployment setup. Only publish material you own or are authorized to distribute. Review the policy templates before launch.
